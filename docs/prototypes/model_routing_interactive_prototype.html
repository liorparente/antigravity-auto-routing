אינטגרציית Qwen 3.8 27B המקומי בתהליך העבודה

הרץ מודל מקומי ב-LM Studio בקוונטיזציית 6-bit (MLX על Apple Silicon) עבור משימות רגישות, אפס עלות ואבטחה מוחלטת.

1

שער משימות רגישות (Sensitive Gate)

כל משימה הנוגעת בקובצי .env, סיסמאות, מפתחות API או קניין רוחני מנותבת מיידית ל-Qwen ללא יציאה לענן (Fail-Closed).

2

בדיקת 200ms חיה (Probe-First)

לפני פנייה ל-API בענן עבור משימות קלות (בדיקות יחידה/תיעוד), המערכת בודקת האם Qwen טעון ב-LM Studio. אם כן, המשימה רצה מקומית בחינם!

3

בורר ניטרלי בדיוני מועצה

במצב של מחלוקת בין Claude (מתכנן) ל-Codex (מבקר), Qwen פועל כ-Adjudicator אובייקטיבי ממשפחה שלישית ללא עלות טוקנים.
